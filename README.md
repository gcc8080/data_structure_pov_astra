# 秩序之形 · THE SHAPE OF ORDER

一支 **5 分钟、1920×1080、24 fps** 的计算机数据结构动态图形宣传片。
原创程序化电子配乐，120 BPM；中英双语烧录字幕及独立 SRT。
无旁白。不是静态幻灯片，也不依赖远程视频生成服务。

## 观看与制作

成片文件为 `output/shape-of-order.mp4`，在会话中单独交付，不纳入 Git 历史。
下载后放到该路径，用浏览器打开 `review.html` 可播放和按章节跳转。

环境：Node.js 22+、Python 3.11+、FFmpeg（含 libx264）。

```bash
npm ci
python3 -m pip install -r requirements.txt
bash scripts/setup-fonts.sh
npm test
npm run score
npm run render
```

默认渲染 1080p / 24 fps / H.264 + AAC 256 kbps。渲染耗时取决于 CPU。
快速检查：`npm run stills`。720p 版本：`WIDTH=1280 npm run render`。
请勿同时运行两个渲染进程，它们会写入同一个输出文件。

## 视觉与声音

- 深空底色，逐章冰蓝、紫罗兰、玫红、琥珀、薄荷、青柠配色。
- 确定性粒子、透视视差、轨道、发光节点、链路脉冲、索引追踪。
- 空间镜头缓慢环绕与推进，章节通过光圈扩张和短黑场衔接。
- 所有章节边界落在节拍上：30 秒 = 60 拍；每条字幕 6 秒 = 12 拍。
- 原创合成音色：分解和弦、宽立体声铺底、低音、底鼓、军鼓、踩镲及转场空气声。
- 600 拍的统一主时钟；音乐不是从外部歌曲剪辑拼接。

## 源码

`src/story.cjs`：50 条双语字幕与章节配色。  
`src/visuals.cjs`：由时间直接求值的图形与运镜。  
`scripts/score.py`：固定随机种子的原创立体声配乐。  
`scripts/render.cjs`：逐帧渲染、SRT 输出和 FFmpeg 音画封装。  
`scripts/test.cjs`：时间线、双语条数、边界帧与字幕宽度检查。

复杂度曲线是示意图，不是基准测试。链表插入的常数时间前提是已知所需节点；哈希查找的常数时间是良好散列与负载条件下的期望性质；搜索树的对数路径依赖平衡。
